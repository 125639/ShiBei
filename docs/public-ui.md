# 公开站前端与验收

公开站采用独立的 `publication.css` 与 `src/components/public/` 组件，不改变后台工作流、数据库 schema、发布审核与社区评分规则。经典默认配色调整为纸白 / 松绿，其他主题、字体和 Firefly 侧栏仍然可用。

## 主要交互

- **首页**：贝壳视觉区支持鼠标轻微视差与「发现 / 思考 / 表达」切换；动效可暂停，偏好在首次绘制前恢复。首页主题按钮只筛选已加载的最近六篇，完整分类在文章页浏览。
- **导航**：`Ctrl/⌘ K` 搜索、原生对话框焦点管理、Escape 关闭与焦点恢复；移动端有独立菜单。语言切换保留当前路径、查询与锚点。
- **文章列表**：服务端全文列表分页，关键词搜索标题、摘要（含英文）、标签和主题。主题筛选始终可用；网格 / 列表切换与外观面板共用保存的偏好。
- **阅读页**：混合中英文阅读时长、分享复制及剪贴板拒绝时的手动复制、按正文高度计算的阅读进度、返回顶部；已有目录、翻译、评论和视频逻辑不变。
- **关于 / 社区**：统一视觉与中英文页面信息。社区只展示原有评分规则允许的摘要和分数，缺失历史 slug 不生成无效链接。
- **性能与无障碍**：不新增动画依赖；CSS 负责轻量装饰，IntersectionObserver 只触发进入视口的内容。长正文滚动不会触发整页动画扫描。系统「减少动态效果」优先于站内设置；无 JavaScript 时仍可阅读、翻页与提交搜索。

## 实现边界

- 首页、文章页继续使用服务端渲染 / ISR，列表数据继续使用 `public-content` 标签失效。
- 首页与列表缓存保存封面、阅读时长等摘要数据，不把整篇 Markdown 放入列表缓存。
- 文章卡片本身是服务端组件；首页筛选和列表布局控制只接收展示节点与少量元数据。
- 有封面的文章使用 `next/image`，本地图片按尺寸优化，站外封面不新增任意图片优化代理权限；没有封面时使用纯 CSS 图形，不插入虚构文章。
- 未使用页面级 `loading.tsx` 覆盖整个阅读路由：该边界会使部分流式 HTML 依赖脚本揭开。导航 / 搜索进度条保留即时反馈，正文维持不依赖脚本的 SSR。
- `SHIBEI_DIST_DIR` 可选环境变量隔离预览构建。未设置时仍使用标准 `.next`，不改变生产启动方式。

## 本地验收

```bash
npm run check          # ESLint + TypeScript
npm test               # 既有回归套件 + 阅读时长 / 进度 / 筛选边界测试
```

浏览器检查不生成或修改文章，也不调用 AI；正常访问会触发原有访问统计，所以应使用独立测试数据库。

```bash
# 请先按 README 初始化一个独立的测试数据库。
# 下面的环境变量只在当前终端生效，不需要修改正式 .env。
export DATABASE_URL='postgresql://测试用户:测试密码@127.0.0.1:测试端口/测试库'
export SHIBEI_DIST_DIR='.next-preview'
export PUBLIC_URL='http://127.0.0.1:3100'
export APP_MODE='full'
export APP_HOST='127.0.0.1'
export PORT='3100'
export TRUST_PROXY_HOPS='0'
npm run build
npm start

# 另一个终端；已安装的 Playwright 需要有 Chromium 浏览器。
BASE_URL=http://127.0.0.1:3100 npm run test:ui
```

脚本同时支持空站和有文章的站点；卡片、分页、阅读进度等检查只在相应数据存在时执行。要完整覆盖分页，准备超过 24 篇**测试**文章；社区与文章数据不要从正式库复制敏感内容。

默认截图保存到 `/tmp/shibei-public-ui`，可用 `UI_ARTIFACTS_DIR` 指定目录。覆盖 320–1440px、八种界面风格、深色主题、双语搜索与翻页、移动端菜单、动效偏好、剪贴板失败、无脚本阅读以及浏览器水合错误。

预览构建和正式服务不要使用相同输出目录；验收完成后正式部署应重新使用正式环境构建，而不是将含测试内容 ISR 缓存的 `.next-preview` 直接上线。
