## 实际修复

1. **采集覆盖**：取消国际研究的固定媒体白名单；保留地域过滤与既有出站安全校验。最多三个 Exa 查询串行执行，交错合并、规范化去重，避免首条查询占完正文抓取额度。
2. **资料时效**：未指定历史区间时，前两条查询限制最近 180 天；第三条保留历史背景。明确年份或历史研究不强制当前时间窗口。
3. **正文上下文**：Exa 摘录上限从 2000 增至 6000 字符；选择一个连续的主题相关原文片段而不是只取封面、名单或开头。长文最多选取六条正文级资料，分配更充足且有限的上下文。
4. **引用返修**：规划器也读取与被拒事实有关的正文片段，能定位百分比、数量及千位分隔形式。来源不可支撑时仍须删除/收窄事实，未降低引用或事实门禁。
5. **模型容错**：备用鉴权错误不再覆盖主连接的临时故障；保留每个连接的错误。在同一流水线中复用已经成功的连接，避免审校/返修反复撞向刚超时的主连接；新任务及明确指定模型的测试保持原路由。
6. **任务 UI**：直接展示失败与自动重试原因，提供完整详情入口；刷新失败标记旧快照；只有排队任务时显示排队；日期格式与站点偏移由服务端明确传入，修复中英文浏览器与时区差异导致的 React #418。
