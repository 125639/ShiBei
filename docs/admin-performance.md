# 后台响应速度优化

本次优化不缓存跨请求的管理员身份，不缓存任务状态，也不改发布、评分、同步或权限策略。

## 关键改动

- 将后台工作页放入 `src/app/(console)/admin/(workspace)/` 路由组，URL 保持不变。常驻 layout 负责侧栏、移动菜单和更新提醒；切页只替换主内容。登录页不属于这个 layout。
- 各页仍调用 `requireAdmin()`，避免把可复用 layout 当作唯一授权边界。`getSession` 只使用 React 请求级 `cache` 合并同一次 RSC 渲染中的重复 JWT/数据库校验，每个新请求仍检查 `tokenVersion`。
- 后台导航、表格行、分页和仪表盘入口关闭默认视口预取；侧栏只在鼠标/键盘明确停留时预取一个目标，离开即取消等待。链接本身的 pending 状态即时显示。
- 搜索使用 `next/form` GET 客户端导航，保留侧栏和语言控件；POST 表单继续沿用原有校验、提交与重定向行为。
- 文章编辑器仅在可见预览需要时加载 Markdown/净化模块。隐藏新建表单、纯编辑模式和空文本不预先解析。原生 textarea、预览净化与专注模式保留。
- 设置页不再等待上传目录扫描；进入存储标签后请求认证的 `/api/admin/storage/usage`，结果 `private, no-store`，支持失败重试和手动刷新。模型面板代码也按需加载。
- 仪表盘的同表计数合并；任务概览共用一次状态聚合，七天窗口使用数据库时间。任务列表每页 40 条，稳定按创建时间和 id 排序；任务详情不再查询未展示的原始 Markdown、文章正文或完整视频对象。
- 自动刷新等待上一次路由刷新完成；隐藏标签页、离线和正在输入时不刷新。只在当前列表确有活跃任务时轮询；紧凑进度条不再无意义地每秒更新隐藏计时。
- 更新提醒移至右下角，不再挡住左侧导航。

## 验证

```bash
npm run check
npm test
BASE_URL=http://127.0.0.1:3100 npm run test:admin-ui
```

浏览器检查需要本地 `.env` 指向对应数据库，读取管理员 id、tokenVersion 和 AUTH_SECRET，在内存签发 20 分钟测试会话；不打印令牌、不改密码、不生成或修改文章、不触发模型调用。BASE_URL 仅允许本部署的主机名或回环预览。截图和不含令牌的指标默认写到 `/tmp/shibei-admin-ui`，可通过 `ADMIN_UI_ARTIFACTS_DIR` 修改。

检查匿名拦截、失效会话、页面正常加载、侧栏节点保持、请求不扩散、客户端搜索、编辑器延迟加载/预览/专注模式、存储按需加载/失败重试、任务列表条数限制以及移动菜单。数据超过一页时额外检查任务翻页。

迁移路由组后，旧的 Next 生成类型可能引用旧源文件路径。使用新的构建目录编译，或通过 `next typegen` 重新生成类型，不要删除/重建正在提供服务的整个 `.next` 目录。部署使用独立构建、可回滚备份和正式配置，不能直接上线预览环境的 ISR 缓存。
